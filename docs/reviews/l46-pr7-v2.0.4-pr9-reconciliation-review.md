## 3. Architecture-Before-Runtime Trace

1. **Two-Tier Transcript Budget Architecture (`Agy-Context-Saver` `L52`, `bin/agy-context.mjs`, `lib/transcript-core.mjs`, `docs/tools.md:80-84`):**
   - *Design thesis & contract:* Default inline `read`, `outline`/`summary`, `query`, and `tools` outputs stay within `INLINE_SAFE_CHARS` (9,200 UTF-8 bytes) across both Markdown and `--json` so standard tool calls avoid Antigravity's ~10 KB shell spillover. `step` defaults to `MAX_FIELD_CHARS` (24,000 B). Explicit `--full`, `--max-chars <N>`, or `--out <path>` opts into `MAX_DEEP_OUTPUT_CHARS` (524,288 B).
   - *Implementation divergence:* While inline `read`, `query` (default), `outline`, `tools`, and `--out` JSON/Markdown paths respect those ceilings, two sibling paths break symmetry: (a) `query --summary --json` and `read --summary --json` discard the formatted summary lines in `res.text` inside `serializeTranscriptResult()` and feed raw unsummarized `items` into `serializeBoundedJsonPayload()` (`PR7-RUN-002`, dropping to 0 items when a single match exceeds 9.2 KB); and (b) `export --sanitized` bypasses `serializeBoundedJsonPayload()` on stdout `--json` (spilling 24,682 B in this review), ignores `--full`/`--max-chars`, hardcodes `maxOutputChars: 64000` on `--out`, and trims Markdown exports against pretty-printed JSON size (`PR7-RUN-003`).
2. **Parent Transcript Access Governance & Precedence (`L36`, `L38`, `L39`, `L45`, `execution-guard-hook.mjs:2145-2250`, `transcript-core.mjs:610-771`):**
   - *Design thesis & contract:* Child agents inherit 5-tier precedence (`1. Owner -> 2. CLI --deny -> 3. CLI --allow -> 4. First-line launch directive -> 5. Cohort mode`). `--reset` clears the caller's policy and restores operator visibility via `agy-context status`.
   - *Implementation divergence:* `Agy-Squad/mcp/briefs.mjs:205-208` stamps `[agy-transcript-access: deny]` on Line 1 of every standard leaf specialist. In `transcript-core.mjs:717-720`, `--reset` deletes `store.policies[ownerId]` only, while `formatTranscriptAccessStatus()` (`L610-628`) reports `Transcript Access Policy: OPEN (default — all sessions permitted)` even though sibling active swarm children stay locked at Tier 4 `[mode=deny, source=launch-directive]` (`PR7-RUN-001`, confirmed live in `72cc4786` Step 74). Wave 2 only demonstrated child `--reset` recovery on `5096a4bf` because Coordinator manually stripped Line 1 from `squad_planner`'s output before calling `swarm{action: "add"}`.
3. **Cross-Platform Installer Parity & Multi-Wave `/swarm` Reuse (`Agy-Squad` `L43`, `L46`, `L49`, `L51` + `scripts/install-register.mjs`):**
   - *Design thesis & contract:* Host-materialized plugin MCP schemas under `~/.gemini/antigravity/mcp/agy-squad_agy-squad/` are part of normal Antigravity `hub` loading and must not false-trigger `globalDuplicate`, while tarball-installed shims must support self-deletion on Windows without masking cleanup errors.
   - *Implementation verification:* `detectExistingInstallation()` (`scripts/install-register.mjs:516-530`) and `runInstall()` (`L878-895`) now preserve `agy-squad_agy-squad` when `pluginRegistered && !hasGlobalMcpEntry` and sweep it on version mismatch or duplicate installs (`agy-squad status --json` exits 0 with `isComplete: true`). However, downstream governance docs and skills lag live Wave 2 observations: `l46-wsl-live-swarm-transcript-verification.md` inaccurately explains `transcript-index.md` truncation and fails `diagnose.mjs`'s auto-picked `validateTargetReviewLedger` (`PR9-DOC-001`), while `swarm-governance` does not warn against combining builtin `swarm_monitor` (`read_board{since: 0}`) with reused multi-wave boards (`PR9-SKILL-001`).
