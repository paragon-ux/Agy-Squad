## 4. Root-Cause Clusters (Non-Table Summary)

1. **Verdict Parser Prose Leakage:** Strict verdict headers coexist with unscoped table/prose regexes in `mcp/verdicts.mjs`, crashing `BLOCKED`/`PASS` synthesis reports and draft `bundle-init`.
2. **Self-Diagnosis Validator & Schema Drift:** `diagnose.mjs` skips Section 4 tables, omits `*` normalization on bold IDs, mis-gates `entryShare` vs `proseShare`, includes test-fixture writes inside `tHandoff`, ignores `/swarm` `1805 B` briefs, and truncates hyphenated IDs in `extractCohortFindingIds`.
3. **Manifest, Skill & Reference Alignment:** `self-diagnosis-manifest.json` omits core files in specialist scopes and carries subagent-era Lead bundling steps; `swarm-governance` cites un-truncated `@<squad>-lead` names; `pr-review-standard.md` and `report-template.md` diverge on Sections 4–6; `docs/tools.md` misstates `-32602` vs `isError`, `integrity_auditor*`, and `./` flags.
4. **Orchestration, Installer & Companion Parity:** `inspectHandoffs`, `collectReportSlots --strict`, `bundleReports`, `resolveIntegrityAuditor`, and `bin/agy-squad.mjs` `./` handling disagree on edge cases; installer status hides malformed JSON / `docsReady`; `Agy-Context-Saver` `execution-guard-hook.mjs` still blocks references to `mcp/index.js`.
5. **Token & I/O Headroom:** Duplicated `reportSlot` paths, verbose `alignmentLine`/lead boilerplate, pretty-printed `squad_planner` JSON, uncached `normalizeScopePath`, 7-spawn CLI startup overhead, and standalone `fsyncSync` latency dominate overhead.
