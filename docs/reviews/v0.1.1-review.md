## 3. Architecture-Before-Runtime Trace

1. **Workspace Root Resolution & Propagation (`args.workspace` > `initialize roots` > `AGY_SQUAD_WORKSPACE` > `cwd`):**
   - `mcp/index.js` captures `sessionWorkspace` from `initialize` (`workspaceFolders[].uri`, `rootUri`, `rootPath`), trimming and validating `file://` URLs case-insensitively while rejecting bare `file://` (`pathname === "/"`), and falls back cleanly on malformed entries.
   - `mcp/dispatch.mjs` (`resolveCandidateWorkspace`, `logicalWorkspaceRoot`, `resolveWorkspaceRoot`) trims explicit and env workspace paths and propagates `delegateWorkspace` through `handleDispatchSquad({ squadId: "all_l1" })` into `mcp/briefs.mjs` (`dispatchCall`) so delegated subagent leads preserve the caller's workspace override.
2. **Symlinked Workspace Manifest Containment (`mcp/dispatch.mjs`, `mcp/planner.mjs`):**
   - When `workspace` traverses a symlink (common in shared worktrees), `logicalWorkspaceRoot` retains the pre-canonical workspace boundary alongside canonical `fs.realpathSync(root)` so valid absolute `manifestPath` arguments inside the symlinked workspace pass logical boundary checks before `fs.realpathSync` + `O_NOFOLLOW` + `/proc/self/fd/${fd}` regular-file containment guarantees remain enforced.
3. **Diagnostic `ENOENT` Guidance & Bounded Reads (`mcp/dispatch.mjs`, `mcp/briefs.mjs`):**
   - Missing default manifests mark `notFound.code = "ENOENT"` so both `handleDispatchSquad` and `handleSquadPlanner` surface `formatNotFoundError` (`Pass 'workspace' ...` or `AGY_SQUAD_WORKSPACE`). Compiled briefs standardize `<=150-line read_file slices (StartLine/EndLine)` + `never unbounded read_file` to prevent pre-tool denials seen during Nov 15 audit runs.
4. **Matched-High Benchmark & Packaging Parity (`benchmarks/`, `scripts/release-preflight.mjs`, `tests/verify-package.mjs`):**
   - `telemetry.json` preserves the Nov 8 Phase 1 baseline verbatim alongside Nov 15 `matchedHighRetest` (`Gemini 4 Hydrogen (High)` across both arms, 6/6 defects, 3.49x wall-clock speedup, 91.1% parent wakeup byte reduction, 60.6% scratch reduction), verified by `verify-benchmark.mjs` (`N1`–`N6` rubric mappings, per-session KB, hashes, and `planSquadCohort` flat `/swarm`).
   - `scripts/release-preflight.mjs` and `tests/verify-package.mjs` enforce `mcp/dispatch.mjs`, `diagnose.mjs`, `self-diagnosis-manifest.json`, `LICENSE`, single-pass glob/negation patterns, and `.tgz`/`.log`/`scratch/` exclusions across the 66-file package (65 pre-ledger + this review ledger).

#### `RT-001` — `dispatch_squad({ squadId: "all_l1", workspace })` drops `workspace` from compiled L1 lead delegation prompts | P1 | Closed
- **Title, priority, status:** `RT-001` — `all_l1` lead delegation prompt drops caller `workspace` override | P1 | Closed
- **Contract provenance:** Cross-workspace MCP invocation contract (`docs/tools.md:12-16`) requiring global plugin installs (`cwd !== repoRoot`) to respect explicit `workspace`.
- **Source evidence:** `mcp/dispatch.mjs:293-298` (`delegateWorkspace`) and `mcp/briefs.mjs:65, 143-149` (`dispatchArgs`).
- **Trigger:** Calling `dispatch_squad({ squadId: "all_l1", workspace: realWs })` from an empty/different fallback directory compiles child delegation instructions without `"workspace"`.
- **Expected / actual:** Expected `Call dispatch_squad with {"squadId":"sq","manifestPath":"swarm-manifest.json","workspace":"..."}`; Wave 1 observed `workspace` omitted from JSON arguments.
- **Impact:** Under global plugin installs where MCP `cwd` or `AGY_SQUAD_WORKSPACE` differs from the target repo, L1 leads lose the caller's `workspace` when delegating to specialists.
- **Required remediation:** Pass `workspace: argWorkspace !== undefined ? root : undefined` through `handleDispatchSquad` (`all_l1`) into `buildSubagentSpec` / `dispatchCall`.
- **Acceptance evidence:** `tests/test-dispatch.mjs:232-244` asserts `"workspace"` presence in compiled `all_l1` lead prompts; verified by direct Node check (`exit 0`).
- **Root cause / related IDs:** `all_l1` omission alongside `mcp/briefs.mjs` template string formatting; related to `RT-003`, `RT-004`.
- **Closure:** Closed in `v0.1.1` Wave 2 (`runtime-mcp-lead` PASS, `audit-runtime-mcp` CLEAN).
