## 5. Atomic Findings (P1, P2, and P3)

### 5.1 P1 Blockers (10-Field Records)

#### `PR15-SEC-001`: `safeWriteFileIfChanged` strips restrictive `0600` permissions on private MCP/config files and writes world-readable backups (CWE-732) | P1 | Closed
1. **Title, priority, status:** `safeWriteFileIfChanged` strips restrictive `0600` permissions on private MCP/config files and writes world-readable backups (CWE-732) | `P1` | `Closed` *(Devin Vulnerability #1, expanded to all 7 user config/backup write sites)*.
2. **Contract provenance:** Standard v1.5.0 `4.11 SEC` (secret hygiene, fail-closed file permissions, CWE-732) and `scripts/install-register.mjs` configuration preservation contract.
3. **Source evidence:** `scripts/install-register.mjs#L204-L240` (`safeWriteFileIfChanged`), plus write sites `#L983` (`mcpBakPath`), `#L990` (`mcpJsonPath`), `#L1023` (`configBakPath`), `#L1033` (`configJsonPath`), `#L1154` / `#L1187` (`commitRestorePlans`), `#L1245` (`runUninstall` `mcpJsonPath`), `#L1253` (`runUninstall` `configJsonPath`).
4. **Trigger:** Running `agy-squad setup`, `restore-backups`, or `uninstall` on POSIX under default umask `022` when `mcp_config.json` or `config.json` has mode `0600`.
5. **Expected / actual:** Expected backups (`*.agy-squad.bak`) and recreated missing targets to be created with `0o600` at open time and existing `0o600` live configs to retain `0o600`. Before remediation (`2f2c19a`), temp files opened with `0644` and replaced the target inode. After `869f9d8` / `1e5a889`, `safeWriteFileIfChanged` reads `statSync(filePath).mode & 0o777` before reading content when `mode === undefined`, creates temp files with `{ flag: "wx", mode: effectiveMode }` + `chmod`, and passes `0o600` for backups and recreated missing targets while keeping `0o755` for launchers/shims (`#L701, #L766`).
6. **Impact:** Eliminated local POSIX credential exposure on shared hosts across `setup`, `restore-backups`, and `uninstall`.
7. **Required remediation:** Preserve existing POSIX mode when `mode === undefined` and explicitly pass `0o600` for `mcpBakPath`, `configBakPath`, and recreated missing restore targets.
8. **Acceptance evidence:** POSIX `umask(0o022)` tests in `tests/test-lifecycle-installer.mjs#L1575-L1636, #L1715-L1717` asserting `0o600` on `mcp_config.json.agy-squad.bak`, `config.json.agy-squad.bak`, preserved `0o600` on live `mcp_config.json` and `config.json` across `setup`, `restore-backups`, and `uninstall`, and `0o600` on recreated missing targets.
9. **Root cause / related IDs:** Atomic temp-file `rename` replaced target inode without preserving source mode; adjacent to `PR15-SCRIPT-001`.
10. **Closure:** Closed in `869f9d8` (verified in `1e5a889`); local `node tests/test-lifecycle-installer.mjs` PASS; independently verified by Gate B auditor `3fe2dbc7-fa5e-4720-89f5-d6987bc82e20` (`PASS`).

#### `PR15-SCRIPT-001`: `restore-backups` permanently deletes primary `*.agy-squad.bak` when live config is missing and backup holds third-party settings | P1 | Closed
1. **Title, priority, status:** `restore-backups` permanently deletes primary `*.agy-squad.bak` when live config is missing and backup holds third-party settings | `P1` | `Closed` *(Devin Bug #1, expanded across both `ownBackupKeys.length === 0` and `ownBackupKeys.length > 0` branches plus repeat-run idempotency)*.
2. **Contract provenance:** `L58` key-scoped merge-restore contract (`scripts/install-register.mjs`: preserve third-party user settings and never destroy user backups without restoring them).
3. **Source evidence:** `scripts/install-register.mjs#L1057-L1160` (`hasForeignBackupData`, `prepareRestoreJsonSection`) and `#L1181-L1201` (`commitRestorePlans`).
4. **Trigger:** Live `config.json` or `mcp_config.json` is missing (`!currentData`), while `*.agy-squad.bak` contains third-party servers, plugins, or top-level keys, and the operator runs `agy-squad restore-backups` or `agy-squad uninstall --restore-backups` (once or repeatedly).
5. **Expected / actual:** Before remediation (`2f2c19a`), both `ownBackupKeys.length === 0` and `ownBackupKeys.length > 0` unlinked `*.agy-squad.bak`. Commit `869f9d8` retained the backup on Run 1; Gate B audit identified `B-SCRIPT-001` where recreating a partial live config caused Run 2 to delete the retained backup. Commit `1e5a889` keeps `content: null` and `unlinkBackupPath: null` with a `[WARN]` operator notice whenever `!currentData && hasForeignBackup`, making repeat `restore-backups` and `uninstall --restore-backups` 100% idempotent while owned-only and empty backups still restore (`0o600`) and clear cleanly.
