# Agy-Squad

Agy-Squad compiles staged subagent payloads and Pointer-Over-Wire briefs for the Antigravity CLI on WSL. Use it alongside Agy-Context-Saver, which handles RTK command rewriting, lifecycle governance, and transcripts.

Start with the [manifest and tool contract](tools.md). Use the [WSL CLI verification checklist](plans/wsl-cli-verification.md) before launching a live squad.
