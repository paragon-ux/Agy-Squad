# `swarm-governance`: Native `/swarm` Execution Modifier

Use `swarm-governance` whenever running a multi-agent team on Antigravity native `/swarm`. It is an **Execution Modifier** that pairs with any Task Spec ([`pr-review`](pr-review.md), [`full-review`](full-review.md), [`self-diagnosis`](self-diagnosis.md), or opt-in flat [`day-one-review`](day-one-review.md)) to add scoped file boundaries, tiny receipts, dual-verdict integrity checks, and clean teardown on top of Antigravity's native board.

## Workflow stages

1. **Step 0: Missing-settings intake (`Coordinator`):** Check whether the user's swarm prompt specifies all four settings: **topology** (`flat` vs. `layered`), **model** (coordinator model vs. explicit pinned model), **workspace isolation** (`inherit` vs. `share`/`branch`), and **report retention** (`--prune` vs. `--keep-reports`). Trigger a single `ask_question` call **iff ANY** of the four settings is absent, asking **only** for the missing ones (recommended defaults: `flat` for inline tasks / `layered` for manifests with leads, coordinator model, `inherit`, `--prune`, plus an independent Integrity Audit); skip Step 0 only when all four are explicitly provided. In `squad_planner`, inline tasks default to `flat` while manifests with `lead` blocks compile `layered` unless `--topology flat` is passed.
2. **Stage 1: Plan, launch & park (`Coordinator` -> `Specialists` + optional `monitor` / `narrator`):** Call `squad_planner` (or `agy-squad plan`) to compile `swarmAdd` payloads, check writable `scopeFiles` overlaps, pin models, and emit `verificationPipeline` commands. Spawn workers via `swarm{action: "add"}`, verify active model IDs via `swarm{action: "status"}`, emit verbatim `open_board` on its own line on launch turns (and on resume turns or when asked while active), and park quiet turns with `swarm_wait` (no `schedule` polling timers).
3. **Stage 2: Slot reports, content gate & flat integrity audit:** Each specialist writes evidence to `scratch/agy-squad/squad-<id>/specialist-<N>/report.md` and posts one single-line `<= 500` UTF-8 byte pointer (`@lead READY <slot> -- <observation>` or `@lead [done] READY <slot> - <observation>`, accepting optional leading `@mention` + `[done]` prefixes and spaced ASCII ` - ` or ` -- ` alongside ` — `) on the board. The lead or coordinator collects isolated slots (`agy-squad collect`), scopes board reads with `read_board{since|seqs}`, verifies cited files/tests, writes `lead/report.md` (`Content Verdict: PASS | FAIL | BLOCKED`), and runs `agy-squad verdict` + `bundle-init --digest`. An independent flat `audit-<id>` worker audits execution traces in one batch pass (reading native `~/.gemini/antigravity*/brain/<id>/.system_generated/logs/transcript.jsonl` and `transcript_full.jsonl` directly standalone, or using `agy-context transcript` CLI calls when optional `Agy-Context-Saver` `2.1.2+` is installed, where transcript access defaults to `OPEN` and operators can opt into `[agy-transcript-access: allow|deny]` on line 1 of worker prompts or via `agy-context transcript access`) to emit `Target Squad`, `Evidence Digest: <64-hex>`, and `Integrity Verdict: CLEAN | INTEGRITY VIOLATION`.
4. **Stage 3: Bundle, resume, or close:** Run `agy-squad verdict --integrity` and `agy-squad finalize <record.json> [--prune [--keep-reports]]` (or granular `bundle`, `verify`, `prune`). Post `[done] <summary>` (no `@`) before pausing with waiting workers or closing so `monitor`'s `*/3` cron cancels cleanly. Resuming a paused swarm cascades top-down (`coordinator -> leads -> workers` in layered mode, or `coordinator -> workers` in flat mode) using a plain resume prompt (`resume your assigned work from where you left off`) and re-emits verbatim `open_board` on its own line on the resume turn (and when asked while active). On close, kill all workers plus `monitor` (`swarm{action: "kill"}`) and complete the [four-check runtime closure gate](../roles-and-workflows.md#3-runtime-closure-checklist-and-hook-boundary).
