## 0. Non-Regression Guardrails (`L1`–`L50`) & Scope Split

Before modifying code or prompt assets, all workstreams must preserve these invariants:

1. **Cross-Platform Security & Symlink Parity (`L46`):**
   - Never drop `lstatSync` / `realpathSync` unconditionally in `mcp/handoffs.mjs` `readOpenedFileWithStat`. Because Windows `fs.constants.O_NOFOLLOW` is undefined (`O_NOFOLLOW ?? 0 === 0`), skipping `lstatSync` / `realpathSync` is valid **only on Linux** when `O_NOFOLLOW` is active and `readlinkSync(/proc/self/fd/${fd}) === file`. Windows and macOS must keep `lstatSync` + `realpathSync`.
   - Top-down `segmentCache` in `normalizeScopePath` (`mcp/planner.mjs`) must preserve external-symlink rejection (`sym-escape`) and broken-symlink case handling (`sym-broken`) verified by `tests/test-planner.mjs`.
   - Windows CLI shims and paths must continue passing Node `22`/`24` matrices on `ubuntu-latest`, `macos-latest`, and `windows-latest`; interactive physical macOS/Windows `agy` desktop `/swarm` testing remains gated explicitly as an open `L46` item until executed on hardware.
2. **Durability vs. Recoverable Scratch I/O (`L4`, `L41`, `L42`):**
   - Retain unconditional `fs.fsyncSync(fd)` inside `publish()` (`mcp/handoffs.mjs`) when writing authoritative cryptographic `report.sources.json` bundles and `bundle-init` records when requested; allow `{ sync: false }` only for recoverable scratch copies (`collectReportSlots` intermediate slot copies and temporary `bundle-init --out` files).
3. **Topology Neutrality & Closure Integrity (`L43`):**
   - Keep `topology.defaultBias: "none (ask user if unspecified)"` in `mcp/planner.mjs` (`tests/test-planner.mjs#L86`). Document `flat` + `inherit` efficiency inside Step 0 guidance rather than altering the planner default.
   - Keep `diagnose.mjs` Section 5 closure check string anchors (`swarm{action: "status"}`, `swarm{action: "kill"}`, `manage_subagents`, `manage_task`, `open_board`) intact when compacting `swarm-governance/SKILL.md`.
4. **Two-Repo PR Separation:**
   - `W1`–`W7` (`130` `Agy-Squad`-scoped items, including `Agy-Squad`'s halves of shared installer items `S2-DEP-001` and `S2-SCRIPT-011`) land in `paragon-ux/Agy-Squad`.
