## [0.2.1] - 2026-11-21

### Changed
- **4-State Standalone Native Fungibility & Optional `Agy-Context-Saver` Decoupling (`scripts/install-register.mjs`, `bin/agy-squad.mjs`, `mcp/briefs.mjs`, `mcp/planner.mjs`, `README.md`, `docs/`, `zensical.toml`)**:
  - **Standalone native JSONL Integrity Audits:** Made `Agy-Squad` 100% standalone with native Antigravity, auditing worker execution traces directly from `~/.gemini/antigravity*/brain/<id>/.system_generated/logs/transcript.jsonl` and `transcript_full.jsonl` in one batch pass (`--no-integrity` and `--allow-unaudited` remain explicit opt-outs, never required for standalone runs).
  - **Zero companion probes or nags:** Removed `agy-context`/`rtk` probes and `[NEXT STEP]` companion nags from `agy-squad setup` and `agy-squad status [--json]`, reminded users to reload Antigravity Desktop IDE after `agy-squad uninstall`, synced optional companion guidance with `Agy-Context-Saver v2.1.2+` (single global `~/.gemini/config/hooks.json` hook, narrow high-ROI RTK pre-gate, unblocked native workspace discovery, `<= 300L / 24 KiB` `read_file` bounds, and opt-in transcript access directives), and excluded internal `docs/plans/` and `docs/reviews/` from Zensical builds via `exclude_docs`.
  - **Validated key-scoped merge-restore backups:** Upgraded `agy-squad restore-backups` (and `uninstall --restore-backups`) to perform validated key-scoped merge-restore from namespaced `*.agy-squad.bak` backups (with read-only legacy `*.bak` fallback), preserving third-party plugins and foreign MCP servers.
- **Lean Packaging & Maintainer Tool Separation (`package.json`, `plugin.json`, `scripts/install-register.mjs`, `scripts/release-preflight.mjs`, `.agents/skills/self-diagnosis/`)**:
  - Shipped the 4 user-facing skills (`pr-review`, `full-review`, `day-one-review`, `swarm-governance`) in the published npm package, excluded repo-only maintainer tooling and internal paths (`.github`, `self-diagnosis`, `scripts/release-preflight.mjs`, `docs/plans`, `docs/reviews`) from both end-user npm tarballs and installer `copyFilter` copies, and slimmed `diagnose.mjs` for source-checkout maintenance.
- **Lean Skills, Step 0 Missing-Settings Intake, Top-Down Resume & Flexible `[done]` Receipts (`.agents/skills/`, `mcp/briefs.mjs`, `mcp/handoffs.mjs`, `mcp/planner.mjs`, `docs/`)**:
  - Triggered a single `ask_question` Step 0 intake in `swarm-governance` iff any of `topology`, `model`, `workspaceIsolation`, or report retention is omitted from the user's swarm prompt (asking only for missing settings; skipping Step 0 only when all four are provided), and locked `topology.defaultBias` semantics (`flat` for inline tasks; manifest-defined for manifests where `lead` blocks compile `layered` unless `--topology flat` is passed).
  - Standardized top-down paused-swarm resume (`coordinator -> leads -> workers` in layered mode, `coordinator -> workers` in flat mode) using a plain resume prompt and verbatim `open_board` Swarm UI card re-emission on launch turns, resume turns, and when asked while active.
  - Trimmed skill and brief boilerplate, switched `bundle-init` to lazy hydration from `plan.workers`, and accepted spaced ASCII ` - ` or ` -- ` delimiters alongside ` — ` plus optional `[done]` markers (`@lead [done] READY <slot> - <obs>`) in Pointer-Over-Wire receipts (`SWARM_MENTION_RESERVE_BYTES` bumped `26 -> 33`, `<= 451` B prefix budget).
- **Compact Footprints & Internal I/O Performance (`mcp/index.js`, `mcp/briefs.mjs`, `mcp/handoffs.mjs`, `mcp/planner.mjs`, `mcp/dispatch.mjs`, `bin/agy-squad.mjs`, `.agents/skills/*/SKILL.md`, `docs/tools.md`)**:
  - Compacted the 5 `SKILL.md` entrypoints from 19,372 B to 16,720 B (-2,652 B total), tightened MCP `tools/list` schema output to 2,718 B while clarifying `manifestPath` accepts workspace-contained relative or absolute paths, switched compiled brief receipts to ASCII `-` referencing `<Report slot>`, and slimmed compiled brief templates (`specialist`: 529 B, `swarmSpecialist`: 682 B, `swarmLead`: 1,041 B, `swarmAuditor`: 1,145 B).
  - Reduced runtime I/O overhead without API changes: threaded per-operation `verifiedDirs` root caches and size-hinted descriptor reads (`readOpenedFileWithStat`), ran single-pass file hashing in `bundle-init --digest`, cached cohort slot directories in `collectReportSlots` with direct atomic overwrite in `publish`, switched `findScopeOverlaps` to an `O(N log N)` sorted prefix sweep, avoided double validation between `planner.mjs` and `briefs.mjs`, hydrated only the target squad in `bundle-init`, removed the JSON stringify/parse round-trip in `agy-squad dispatch`, and lazy-loaded CLI runtime modules in `bin/agy-squad.mjs`.
- **Calibrated `day-one-review` 4-Tier Ship Verdicts, Upfront Cadence Intake & Auto-Fix P0-P3 Boundary (`.agents/skills/day-one-review/SKILL.md`, `references/day-one-protocol.md`, `.agents/skills/pr-review/references/pr-review-standard.md`, `docs/skills/day-one-review.md`, `docs/roles-and-workflows.md`, `package.json`, `plugin.json`, `bin/agy-squad.mjs`, `scripts/install-register.mjs`, `tests/test-run.mjs`)**:
  - **Stage 1 cadence & target-verdict intake (zero anti-anchoring bleed):** Requires confirming review cadence (`r1` only, multi-round `r1 -> remediate -> r2`, or full public-launch gate adding an unanchored live `raw-final`) and, when multi-round or full gate is chosen, target stop verdict (`SHIP NOW` vs. `SHIP WITH MINOR POLISH`) upfront strictly without asking for or injecting bug hypotheses.
  - **4-tier Ship Verdict rubric:** Replaced the unbounded `SHIP WITH QUICK FIXES` bucket with explicit thresholds: `SHIP NOW` (`0` open P0-P3 in-repo defects), `SHIP WITH MINOR POLISH` (`0` P0/P1/SEC blockers and `<= 2` small localized P2/P3 polish items with zero broken install/compile/SDK/core contracts), `FIX BEFORE RELEASE` (`0` P0/P1/SEC blockers, but `>= 3` open P2/P3 items or any contract-breaking P2), and `HOLD BEFORE PUBLIC RELEASE`.
  - **P0-P3 auto-remediation vs. Section 8 residual gate:** Clarified that concrete in-repo P3 findings are user-facing launch defects and MUST be remediated automatically alongside P0-P2 without asking; reserved Section 8 (`Post-Remediation Residuals & Deferred Dispositions`) as the explicit user decision gate for upstream dependencies, intentional behavior/contract trade-offs, policy-gated files (such as benchmark definitions), and subjective suggestions.
  - **Live-run hardening optimizations:** Mandated packed-artifact consumer installation (normal + `--ignore-scripts`), strict `skipLibCheck: false` public typechecking, and live CLI/SDK/MCP dogfooding during `r1` (using hermetic test scripts for synthetic `.system_generated` checks on governance plugins); defaulted line 1 of `r1` and `raw-final` subagent prompts to `[agy-transcript-access: self-only]` (or `deny`) when `Agy-Context-Saver` is installed; added a 2-round escalation stop-rule requiring structural replacement when an ID remains `Open` in `r3`; compacted previously `Closed` P1/P2 items to 1-line rows in `r2+` Section 7 Closure Tables and allowed targeted delta tests on narrow intermediate `r2+` rounds with one full-gate pass on `SHIP NOW`; defaulted Stage 3 remediation to a single coding subagent for repos using native indexers, local daemons, DB locks, or live symlinked plugin/hook files; and added `timeout 5`-bounded CodeQL-class linear-time regex (ReDoS) probes and least-privilege GitHub Actions `permissions:` / `concurrency:` checks to `4.11 SEC` and Stage 3 verification.
